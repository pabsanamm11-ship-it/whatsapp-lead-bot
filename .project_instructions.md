# WhatsApp Lead Bot Manager

## Overview
CRM-style app for managing WhatsApp lead outreach via Twilio. Built for Pablo Sanabria (Sales Manager, EUKAL/Detergentes Naturales S.A., Costa Rica).

## Tech Stack
- Auth: NextAuth v5 with credentials (email/password)
- DB: PostgreSQL via Prisma (tables: User, Account, Session, Lead, Template, Campaign, CampaignLead, MessageLog)
- Twilio SDK for WhatsApp messaging/validation
- UI in **Spanish** throughout

## Color Theme
- Primary: WhatsApp green (HSL 152 69% 47% ≈ #25D366)
- Light background with green accents
- Dark mode supported

## Key Features
1. **Lead Management**: CRUD, CSV import/export, bulk actions, E.164 phone normalization (default +506 for CR)
2. **WhatsApp Validation**: Twilio error 63003 detection for invalid numbers
3. **Message Templates**: With {{name}}, {{phone}}, {{notes}} variable substitution
4. **Campaign Manager**: Draft/Active/Paused/Completed lifecycle, daily limit (max 100), lead selection
5. **Automated Sending**: `/api/cron/process-campaigns` endpoint, client-side 30-min interval + manual trigger
6. **Dashboard**: Stats cards with animated counters, active campaigns, recent logs
7. **Message Log**: Full history with filters (status, date range, pagination)

## Navigation
Sidebar: Panel, Leads, Plantillas, Campañas, Registro

## Twilio Integration
- Server-side only (never expose credentials)
- Env vars: TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, TWILIO_WHATSAPP_NUMBER
- Graceful banner when not configured with link to Twilio console
- Rate limited: 1 request/second for validation, daily cap of 100 messages per campaign
